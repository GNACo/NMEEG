  Binary classification performance using EEG z-score deviations from the
  normative model as features.
  Results obtained via stratified 5-fold cross-validation with in-fold random

  out-of-bag (OOB) resampling for AUC stability estimation.

  split (stratified by age), ensuring the same $n = 134$ held-out subjects
  served as the reference class across all features.
  Features: oscillatory relative spectral power (specparam decomposition)
  across 7 frequency bands $\times$ 5 scalp ROIs
  (Frontal, Central, Parietal, Occipital, Parieto-Occipital).
  \textbf{Bold}: best result per metric within each comparison group.
  Shaded rows indicate the best overall classifier per comparison (highest CV AUC).%
