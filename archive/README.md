# archive/

Material kept for transparency but **not required to reproduce the reported results**.
Nothing here is deleted: every file was moved with `git mv`, so its history is preserved.

- `exploratory_notebooks/` — exploratory and superseded notebooks (model comparisons such as
  HBR/PCNtoolkit/GPR, feature importance, duplicated `modelNormative` copies, early
  harmonization and figure drafts).
- `exploratory_scripts/` — diagnostic scripts used during analysis to choose the
  logit transform (`prototype_logit_blr.py`) and the BLR hyperparameters
  (`diagnose_logit_hparams.py`).
- `superseded_scripts/` — earlier runners and alternative models superseded by
  `testblr.py` / `classify_blr.py` (`run_BLR.py`, `GPR.py`, `hbr_model.py`, `aproach.py`,
  and auxiliary analyses not used in the manuscript).

Paths inside archived files (for example `prepare_datasets/...`) refer to the repository
layout at the time they were archived. They are kept as they were and are not updated.
