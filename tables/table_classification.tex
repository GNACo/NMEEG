  Binary classification performance using EEG $z$-score deviations from the
  normative model as features (all 7 bands $\times$ 5 ROIs and the aperiodic
  exponent, jointly).
  Stratified 5-fold cross-validation with in-fold random under-sampling of the
  majority class, and 50-iteration bootstrap out-of-bag (OOB) resampling for AUC
  stability. Healthy controls (HC) served as the reference class from a single
  global 80/20 train--test split (stratified by age); $n = 133$ held-out HC
  were used in all comparisons. Site harmonization was learned on training HC
  only (neuroHarmonize, ComBat-GAM with smooth age). Oscillatory relative power
  is bounded in $(0,1)$; the normative model was fit on the logit scale and
  $z$-scores were computed in that space.
  \textbf{Bold}: best result per metric within each comparison.
  Shaded rows indicate the best classifier per comparison (highest CV AUC).%
